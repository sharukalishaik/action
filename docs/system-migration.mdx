# System Migration Protocol

This operational runbook outlines the steps required to migrate core database blocks and static assets across environment instances safely.

---

## 1. Pre-Flight Checklist

Before initiating data cluster modifications, engineers must verify the following baseline states:

- [ ] **Replica Consistency:** Run integrity checks across all storage nodes.
- [ ] **Storage Snapshots:** Execute a localized block-level cold backup.
- [ ] **Traffic Drain:** Confirm connection pools are scaling down gracefully.
